עמודות: חותמת זמן · שם מלא · טלפון · דגם / סוג רכב · חודש הטסט · מקור הליד · הערות · סטטוס · תאריך תיאום

> הגיליון נוצר במקור עם עמודת "מספר רישוי"; הרצת `setupSheet` (שלב 3 למטה) מוחקת אותה אוטומטית.

## חיבור הטופס לטבלה (5 דקות)

1. פותחים את הגיליון → **תוספים / Extensions → Apps Script**.
2. מוחקים את הקוד הקיים ומדביקים את כל התוכן של `google-apps-script.gs`.
3. שומרים, ומריצים פעם אחת את הפונקציה `setupSheet` (מאשרים הרשאות בחלון שנפתח) – זה מעצב את הכותרות ומקפיא את שורה 1.
4. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. מעתיקים את הכתובת שמסתיימת ב-`/exec`.
6. פותחים את `script.js` ומדביקים אותה בשורה הראשונה:

```js
const CONFIG = {
  SHEET_ENDPOINT: 'https://script.google.com/macros/s/AKfy..../exec',
  SOURCE: 'דף נחיתה'
};
```

7. רוצים גם מייל על כל ליד? ב-`google-apps-script.gs` מלאו `NOTIFY_MAIL` ופרסמו מחדש (Deploy → Manage deployments → עריכה → New version).

**בדיקה:** פותחים את `index.html`, שולחים פנייה, ורואים שורה חדשה בגיליון.

> אם `SHEET_ENDPOINT` ריק – הטופס עדיין עובד ומציג הודעת הצלחה, והלידים נשמרים מקומית בדפדפן.
> אפשר לשלוף אותם בקונסול עם `exportLeads()` (מחזיר CSV).

## העלאה לאוויר – GitHub Pages + carweb.online

האתר מתפרסם אוטומטית מענף `main` (תיקיית השורש) של
[eranmx-spec/CARWEB](https://github.com/eranmx-spec/CARWEB).
כל `git push` לענף `main` מעדכן את האתר החי תוך כדקה.

הדומיין המותאם מוגדר בקובץ `CNAME` שבשורש הפרויקט (`carweb.online`) – אין למחוק אותו.

**רשומות A** עבור הדומיין הראשי (`@` / carweb.online):

```

185.199.110.153

```

**רשומות AAAA** (מומלץ, לתמיכה ב-IPv6):

```

2606:50c0:8002::153
2606:50c0:8003::153
```

**רשומת CNAME** עבור `www`:

```

```

אחרי שה-DNS מתעדכן (בין דקות למספר שעות), נכנסים ל-
**Settings → Pages** בריפו ומסמנים **Enforce HTTPS** – גיטהאב מנפיק תעודת SSL חינם.

בדיקה מהירה מהטרמינל: `nslookup carweb.online 8.8.8.8`

> אחסון חלופי (אם יוחלט לעזוב את Pages): הדף סטטי לחלוטין ואפשר לגרור את התיקייה
> ל-Netlify / Vercel או להעלות ל-`public_html` בכל שרת.

## תקנון האתר – `terms.html`

עמוד נפרד, מקושר בדיסקרטיות משני מקומות בלבד: שורת הפוטר בדף הראשי, ושורת אישור זעירה מתחת לכפתור השליחה בטופס
("שליחת הפרטים מהווה אישור לכך שקראתם והסכמתם לתקנון").

התקנון בנוי סביב עמדה משפטית אחת: **מפעיל האתר מספק שירות העברת פניות (לידים) בלבד, וכל האחריות היא של המוסך המטפל.**
16 סעיפים, כולל הגבלת אחריות מפורטת, תקרת פיצוי, שיפוי, פרטיות ומאגר מידע, סמכות שיפוט ותקופת התיישנות מוסכמת.

### ⚠️ חובה לפני פרסום

1. **למלא את ארבעת מחזיקי המקום** המסומנים בצהוב בעמוד: שם מפעיל האתר, ח.פ./ת.ז., כתובת (סעיף 1.1) וכתובת דוא"ל לפניות (סעיף 14.1).
2. **להעביר את הנוסח לעורך דין ישראלי**. המסמך נוסח כטיוטה מקצועית אך אינו תחליף לייעוץ משפטי, ואין ולא יכולה להיות ערובה לתוצאה משפטית.
3. **ליישר את תוכן השיווק לעמדה המשפטית.** דף הנחיתה כתוב היום בגוף ראשון כמוסך ("אנחנו לוקחים את הרכב למכון הרישוי", "מוסך מורשה משרד התחבורה", התחייבות "עובר או שאנחנו חוזרים"). בית משפט בוחן את המצג הכולל כלפי הצרכן ולא רק את התקנון — ותקנון הסותר את מה שהאתר מבטיח בכל עמוד עלול להיחלש מאוד. אם מפעיל האתר אינו המוסך, יש לשנות את הניסוח ל"רשת המוסכים השותפים שלנו".

## מדידה (אופציונלי)

`script.js` כבר יורה אירוע המרה אם מותקן פיקסל:
- Google Analytics / Ads → `gtag('event','generate_lead')`
- Meta Pixel → `fbq('track','Lead')`

מספיק להדביק את סקריפט הפיקסל ב-`<head>` של `index.html`.
